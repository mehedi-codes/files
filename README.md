## ✨ Features

- 📂 **Create & Organize** - Easily create and manage folders and files
- ✏️ **Edit Files** - Built-in text editor for quick edits
- 🔍 **Search & Filter** - Quickly find files and folders
- ✏️ **Rename** - Rename files and folders with ease
- 🗑️ **Delete** - Remove unwanted files and folders
- 🎨 **Intuitive UI** - Clean, user-friendly interface
- ⚡ **Fast Performance** - Built with Vite for instant development experience

## 🚀 Quick Start

### Prerequisites
- Node.js (v16 or higher)
- Bun package manager

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/mehedi-codes/files.git
cd files
```

2. **Install dependencies**
```bash
bun install
```

3. **Start the development server**
```bash
bun run dev
```

4. **Open your browser**
Navigate to `http://localhost:5173` to start using the file manager.

### Build for Production
```bash
bun run build
```

## 💻 Usage

1. **Create a Folder** - Click the "New Folder" button and enter a name
2. **Create a File** - Click the "New File" button and choose a location
3. **Edit a File** - Double-click a file to open it in the editor
4. **Search Files** - Use the search bar to find specific files
5. **Rename** - Right-click on any item and select rename
6. **Delete** - Right-click and select delete to remove files
